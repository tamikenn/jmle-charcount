# jmle-charcount

日本語テキストの文字数を数えるツールです。第58回 日本医学教育学会大会のポスター発表
**「医師国家試験問題の文字数に関する定量的分析 ― 第101回〜第120回 20年間の推移 ―」**
で用いた計数規則を、そのまま単体で使える形にしたものです。

**→ ブラウザですぐ使う: https://tamikenn.github.io/jmle-charcount/**

インストール不要、単一ページで完結します。入力したテキストはブラウザ内だけで処理され、
どこにも送信されません。

## 計数規則

主指標(学会抄録と同一の定義):

- **ひらがな・カタカナ・漢字・英字(ギリシャ文字を含む)・数字を 1字＝1カウント**
- **句読点・記号・スペースは数えない**

前処理として Unicode NFC 正規化を行い、制御文字・書式文字(カテゴリ Cc/Cf)を除外します。
副指標として、句読点・記号を含む「総印字文字数」(スペースのみ除外)も同時に表示します。

文字種は8クラス(漢字・ひらがな・カタカナ・英字・数字・句読点・記号・その他)に分類され、
主指標に算入されるのは前半5クラスです。

## 詳細データ

ポスター発表の図表と実数値(回別集計・種別ごとの分布・感度分析)を
**https://tamikenn.github.io/jmle-charcount/data/** に掲載しています。試験問題の本文は含みません。

## ファイル

| ファイル | 用途 |
|---|---|
| `index.html` | ブラウザ版(単体で動作・外部依存なし) |
| `count.py` | Python 実装(標準ライブラリのみ) |
| `count.js` | JavaScript 実装(ブラウザ / Node 共用) |

## Python から使う

```bash
python count.py "72歳の男性。3日前から38.5℃の発熱と咳嗽が出現した。"
cat article.txt | python count.py
python count.py --self-test
```

出力:

```json
{
  "body": 32,
  "printed_total": 36,
  "with_whitespace": 36,
  "by_class": { "digit": 4, "hiragana": 9, "kanji": 17, "katakana": 2, "punct": 4 },
  "kanji_pct": 53.1,
  "latin_pct": 0.0
}
```

`body` が主指標です。

## 実装の一致について

3つの実装は同一の分類結果を返すことを確認しています。

- 本ツールの Python 実装 ↔ 研究本体の分類器:23,960 codepoint で不一致 0
- JavaScript 実装 ↔ Python 実装:23,960 codepoint で不一致 0

数字の判定は Python の `str.isdigit()` に合わせてあります。上付きの `²` は数字として数え、
分数の `½` は数えません(JavaScript 側は該当する128文字を明示列挙して一致させています)。
